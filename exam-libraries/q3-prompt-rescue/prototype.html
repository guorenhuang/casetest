分镜 Prompt · 诊断工作台（原型）

总览 system-design requirements

待诊断 Prompt（试卷原样）

你是一个资深的短剧分镜师，请根据用户给的剧情，生成详细的分镜表。
请尽可能详细，越详细越好，把你能想到的都写出来。
输出 JSON 格式，字段你自己设计。
注意要符合年轻人喜欢的风格，有爆点。
如果剧情不合适，就自己改一下让它更适合短剧。
剧情：{plot}

检查单（示意 · 以 observations 为准）

  • 输出长度是否失控（证据行号）
  • JSON 是否可解析（证据）
  • 风格是否漂移（同 plot 多次对比）
  • 是否篡改用户设定（diff 剧情要素）
  • ≥4 条问题写入 issues.md

真实交付为 markdown：observations → issues → fixed_prompt（映射表）→ before_after。
