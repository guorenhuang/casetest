# 【关键转折点】

> 试卷框选：那一次让项目从「卡住 / 一团乱」变「能跑」的 AI 产出。

## 转折点内容（摘要）

在 **开发与 Docker 同源托管** 上，采纳了：**生产路径由 FastAPI 直接挂载前端 `dist`**，并让环境变量 **`STATIC_DIR`** 指向同一构建产物——这样 `fetch('/api/...')` 与静态资源 **同源**，不再需要为 demo 单独配一层 Nginx 或猜 Vite preview 端口。

## 为什么是转折点？

此前同时维护「纯 API 后端 + dev 前端代理」与「容器内又该谁暴露 8000」容易错位；统一到 **单端口出页面 + API** 后，**一键 `docker compose up`** 与本地 `uvicorn` 行为对齐，核心演示路径（加载示例 → 编辑 → 生成 prompt → 导出）一次打通。
