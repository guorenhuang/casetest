# 【我不接受 AI 建议】

> 试卷要求：AI 给过看似合理但你拒绝的时刻 + 理由。

## 建议是什么？

AI 曾建议：**分镜表完全用模型自由生成 JSON schema**（字段名、层级结构每次可不同），前端用「递归渲染任意 JSON」搞定。

## 为什么拒绝？

1. **题目 (b)** 强调「前端表格展示 + 一键导出」——若 schema 漂移，表格列与 PATCH 语义无法稳定绑定，导出 CSV 也会变成「拍脑袋列顺序」。  
2. 与 **Q3 试卷反面教材**同源风险：上游结构不稳定会把解析压力甩给前端/下游绘图管线。  
3. 短周期内更值得固定 **SQLite 列 + Ant Design Table 受控字段**，模型只填充「英文 prompt」等少数扩展列。

## 结果

保留稳定列：`shot_number`、`description`、`camera`、`duration_sec`、`style_hint`、`english_prompt` 等；生成接口在列内填充，不因模型幻想结构而破坏表头。
