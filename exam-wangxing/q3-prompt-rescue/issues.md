# issues.md

> R2：每条含 **现象 + 证据片段 + 为何是问题**。

## I-1 — 输出超长且字段不可控

- **现象**：单次分镜条目数远超下游可承载，字段名中英文混用。
- **证据片段**：observations Run#1 raw 中出现 18+ 条分镜且含「超长文学化描述」。
- **为何是问题**：拖垮 token 与下游 schema 校验，解析成本不可控。

## I-2 — 非合法 JSON

- **现象**：输出夹带说明文字、注释或尾逗号。
- **证据片段**：raw 中含“以下为分镜 JSON”前缀或 `/* 注释 */`。
- **为何是问题**：strict JSON.parse 失败，线上流水线直接报错。

## I-3 — 风格锚点主观漂移

- **现象**：同一任务多次运行风格描述互相矛盾。
- **证据片段**：不同 run 的「氛围」在甜宠/赛博/文艺间跳变。
- **为何是问题**：后期无法统一调色与剪辑节奏。

## I-4 — 篡改用户设定

- **现象**：在未授权情况下改写人设或主线。
- **证据片段**：raw 出现「魔改剧情摘要」「为短剧爽感已改写」前缀。
- **为何是问题**：用户核心设定丢失，合规与舆情风险上升。
